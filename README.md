## English

### ✨ Features

- **🎮 Automatic Game Detection**  
  ExtraVibrance activates only when a selected game is in the foreground and restores your normal colors when you leave.

- **🎨 NVIDIA Digital Vibrance**  
  Uses NVIDIA's native Digital Vibrance technology, just like the NVIDIA Control Panel, with no FPS impact.

- **🌈 Extra Saturation Mode**  
  Go beyond the standard 100% saturation limit using an additional Windows color filter.

- **🖥️ Game & Monitor Selection**  
  Choose exactly which games should trigger ExtraVibrance and which monitor to apply it to.

- **⌨️ Custom Hotkeys**  
  Configure your own keyboard shortcut to instantly enable or disable the effect.

- **🚀 Lightweight & Automatic**  
  Runs quietly in the system tray, with optional automatic startup when Windows boots.

### 📋 System Requirements

| Component | Requirement |
|---|---|
| Operating System | Windows 10 / Windows 11 |
| Graphics Card | NVIDIA GPU |
| Runtime | .NET 10 Desktop Runtime |
| Additional | Microsoft Edge WebView2 Runtime |

### 🔒 Safe by Design

ExtraVibrance works at the display level. It does not inject code into games, modify game files, or interact with game memory.

## Español

### ✨ Características

- **🎮 Detección automática de juegos**  
  ExtraVibrance se activa únicamente cuando uno de tus juegos seleccionados está en primer plano y restaura los colores normales cuando salís del juego.

- **🎨 NVIDIA Digital Vibrance**  
  Utiliza la tecnología nativa de NVIDIA, la misma que encontrás en el Panel de Control de NVIDIA, sin afectar los FPS.

- **🌈 Modo de saturación extra**  
  Superá el límite estándar del 100% de saturación mediante un filtro de color adicional de Windows.

- **🖥️ Selección de juegos y monitores**  
  Elegí qué juegos activan ExtraVibrance y en qué monitor querés aplicar el efecto.

- **⌨️ Atajos de teclado personalizables**  
  Configurá tu propia combinación de teclas para activar o desactivar el efecto al instante.

- **🚀 Ligero y automático**  
  Funciona discretamente desde la bandeja del sistema y puede iniciarse automáticamente junto con Windows.

### 📋 Requisitos del sistema

| Componente | Requisito |
|---|---|
| Sistema operativo | Windows 10 / Windows 11 |
| Tarjeta gráfica | GPU NVIDIA |
| Runtime | .NET 10 Desktop Runtime |
| Adicional | Microsoft Edge WebView2 Runtime |

### 🔒 Diseñado para ser seguro

ExtraVibrance funciona a nivel de pantalla. No inyecta código en los juegos, no modifica archivos ni interactúa con la memoria de los procesos.
